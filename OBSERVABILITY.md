# Observability

Structured local events carry time/sequence, severity, component/event ID, correlation ID, build/content versions, bounded attributes and redaction class. Study free text is excluded by default.

Health UI distinguishes healthy, disabled, unconfigured, unavailable and stale-policy states for DB, content packs, backups, model transports, MCP peers and source freshness. Process existence alone is not a health proof.

Remote telemetry is off by default. Any optional export shows category and destination; crash handoff has separate consent.
