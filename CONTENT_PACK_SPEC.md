# Content Pack Specification

A pack contains manifest, semver, schema version, compatible app range, source ledger, claim ledger, curriculum graph, original question templates/instances, explanations, vocabulary/formula assets, calibration metadata, licenses/attribution, and detached signature. Installation verifies schema, signature, hashes, compatibility, provenance completeness, prohibited-source scan, answer consistency, and reviewer state before atomic activation. Previous signed pack stays available for rollback.
