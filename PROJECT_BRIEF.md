# Project VECTOR

## Mission
Build a high-trust local PC application for ASVAB/AFQT preparation that remains genuinely useful offline and uses AI as an optional accelerator rather than an unverified answer engine.

## Differentiators
- Original, provenance-tracked question factory rather than copied/leaked banks.
- Diagnostic skill graph + adaptive daily plan + spaced repetition.
- CAT-style and paper-style simulations based only on public behavior/timing data.
- Readiness estimates with uncertainty and calibration, never fake official-score precision.
- Versioned branch/composite/job data with freshness and recruiter-verification warnings.
- Fully local GGUF path plus officially supported native-client LLM transports.
- Evidence Vault as local source of truth; Gemini Notebook as optional companion.
- MCP client and server for agent/writing-tool interoperability.
- Privacy-first crash flight recorder and reproducible crash -> isolated repair -> GraphLock -> PR workflow.
- Offline core, no ads, no account requirement, commercial-license gate.

## Users
Primary: incoming U.S. military enlistment applicants and delayed-entry candidates. Secondary: independent tutors, parents/guardians and adult learners. Internal: curriculum reviewers and authorized software maintainers.

## Non-endorsement and integrity
VECTOR is independent commercial prep software. It does not administer the ASVAB, determine enlistment eligibility, guarantee a job, or imply DoD/MEPCOM/service endorsement. Claimed real/current ASVAB questions are treated as controlled material and are not accepted into the corpus.

## Success
Every core flow works with networking disabled; every ACTIVE practice item has answer proof and provenance; all mutable policy/test data is versioned; provider credentials stay in provider-owned clients; backups and forced-kill recovery are proven; exact-artifact release gates and GraphLock accounting are complete before GA.
