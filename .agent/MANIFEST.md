# GraphLock Manifest - Project VECTOR

This pack is the implementation and verification blueprint for Project VECTOR. Root product documents define intent and architecture. `.agent/specs` define contracts. `.agent/execplans` define graph node execution. `.agent/verification` defines independent proof. No generated evidence in this blueprint is a claim that the future product already passes.

Canonical registries:
- Requirements: `REQUIREMENTS.csv`
- Definition of done: `.agent/verification/DOD_REGISTRY.csv`
- Verification tests: `.agent/verification/MASTER_TEST_REGISTRY.csv`
- Functional outcomes: `.agent/verification/FUNCTIONAL_PROOF_MATRIX.csv`
