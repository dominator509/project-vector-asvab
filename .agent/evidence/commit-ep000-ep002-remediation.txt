EP-000 REMEDIATION

Found a substantive gap: EP-000's stated purpose includes "toolchain pins", and
the repository had NONE. Dependencies were pinned by Cargo.lock and
pnpm-lock.yaml, but the compiler itself was unpinned, so identical sources could
produce a different artifact. Added:

  rust-toolchain.toml   channel = "1.97.1" (exact, not a range, so a mismatch
                        fails loudly rather than silently using another compiler)
  .nvmrc                24.14.1
  package.json          engines { node, pnpm } and packageManager pnpm@10.34.5

Verified the workspace still builds and the desktop suite still passes under the
pins. Recorded the lockfile digests so a later change to either is detectable.

Regenerated every gate log from real runs, with the logs themselves committed
rather than only their hashes.
