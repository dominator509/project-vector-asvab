MUT-I9 NOTE — a redundant guard, now made load-bearing:
  Removing the explicit absolute-path guard changed nothing, because the
  containment fall-through already rejected "/etc/passwd". Analysis in
  absolute-path-guard-analysis.py showed why: absolute paths normalize to a
  form outside the root, so containment catches them incidentally.
  The guard is NOT redundant for the case where an absolute path *starts with*
  the root text, e.g. "/content/lesson.md". That case is now tested directly
  (an_absolute_entry_is_refused_even_when_its_root_prefix_matches), and MUT-I9
  is detected on retry. An absolute entry ignores the extraction root entirely,
  so accepting it because its text matches would be a real escape.
