REQ-053 / REQ-037 (artifact identity): six components are bound — binary,
migrations, content, SBOM, third-party licenses and the build commit. The
previous implementation bound only four, omitting licenses and the commit, so a
license change or a different commit would not have invalidated the identity.
It also hashed the literal string "MISSING" for an absent file, so a manifest
built from entirely missing inputs still produced a confident-looking digest.
Missing is now a hard error.

Verification re-derives every digest from disk rather than trusting the
manifest. Proven live: the real binary verifies clean, and the SAME check
against a copy with ONE byte flipped fails with an exact recorded-vs-actual
mismatch.

in node_modules/.pnpm, because pnpm-lock.yaml records versions but not licenses.

distinct licenses (MIT 110, Apache-2.0 8, ISC 8, BSD-2-Clause 2, BSD-3-Clause 2,
CC-BY-4.0 1) and correctly surfaced caniuse-lite's CC-BY-4.0 as
attribution-required rather than waving it through. A third-party notices file
is generated from the same data.
