MOTIVATION SEPARATION (REQ-045)

MUT-M1: motivational field added to SkillEstimate (streak)
  change : selection.rs  add `pub streak: u32` to SkillEstimate
  result : COMPILE ERROR (E0063: missing field `streak` in initializer)
  verdict: DETECTED — by the compiler, which is stronger than a test failure.
  note   : the first attempt at this mutation was reported as SURVIVED, which
           was wrong: the test binary had not rebuilt, so the old artifact ran.
           On a clean rebuild the mutation fails compilation at every
           construction site. This is the strongest possible form of the
           separation guarantee: a motivational signal cannot be added to the
           planner's input type without breaking the build.
           A second test, the_shape_guard_flags_a_widened_input_set, covers the
           runtime shape check directly so the guard is not vacuous.
