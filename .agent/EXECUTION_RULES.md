# Execution Rules

- One node, one leased writer per production path.
- Requirement and acceptance test precede production code.
- Do not edit tests or gates merely to convert red to green.
- Every external provider is optional unless a requirement explicitly says otherwise.
- Core study, analytics, and authored content work offline.
- Treat current provider terms and military policy data as versioned evidence, not timeless constants.
- Preserve the local-first architecture and future SyncPort seam; do not smuggle a cloud dependency into the core.
- Keep research/content ingestion separate from production learning packs; only reviewed signed packs are teachable truth.
