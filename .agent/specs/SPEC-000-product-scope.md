# SPEC-000 Product Scope

Project VECTOR is a Windows-first local desktop study system for ASVAB/AFQT preparation. It is educational software, not an official military testing product. Required outcomes map to REQ-001 through REQ-060. Core study paths function without a network. Cloud/provider features are optional adapters. The application never acquires controlled test questions, never claims DoD endorsement, and never labels an internal prediction as an official score.

Acceptance: OUTCOME-01 through OUTCOME-15 in the functional proof matrix each have artifact-level proof before release.
