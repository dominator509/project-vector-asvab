# Release gate

GA requires all P0 requirements/live-fire outcomes, zero unresolved critical/high release blocker, exact signed artifact install/upgrade/rollback, 484 registry IDs accounted, all applicable DOD clauses, SBOM/license/content review, privacy review, manual accessibility, representative UAT, current critical source/provider policy, backup/recovery drill, performance and soak gates. Otherwise it is a candidate, not production-ready.
