# Scoring and readiness

Separate four concepts:
- Practice score: deterministic result for a VECTOR session.
- Skill mastery: internal estimate from learner evidence.
- Readiness estimate: calibrated product prediction/band with uncertainty.
- Official/user score: externally obtained score entered by the learner and labeled as such.

CAT-style practice follows public constraints but uses VECTOR's documented adaptive selector, never a claimed reconstruction of confidential official scoring/adaptation.

Until VECTOR has a defensible validation cohort, show mastery/readiness bands instead of faux-precise predicted percentiles. Any later model version records cohort definition, feature schema, calibration curve, error metrics, interval coverage, drift checks and sample-size rules.
