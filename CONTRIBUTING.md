# Contributing

Work from the next GraphLock ExecPlan only. Every behavior change maps to requirements/tests. New dependencies require necessity, maintenance and commercial-license review. New content requires provenance and QA. Provider integrations never access undocumented OAuth/token storage.

For defects: reproduce, add regression proof, make the smallest architectural fix, run targeted gates then full verify. Never weaken the oracle to make a patch green.

## Copyright in contributions

This project is proprietary; see `LICENSE`. Contributions are accepted **only**
under an agreement that assigns copyright in the contribution to the copyright
holder, or grants a perpetual, worldwide, royalty-free, irrevocable licence to
use, relicense and distribute it.

Do not open a pull request unless you are able and willing to do that. A
contribution without such an agreement cannot be merged: it would place part of
the work under terms the project cannot relicense, which breaks the single
ownership a proprietary product depends on.
